# Introduction

## 1.1 Why is software slow

- 왜 하드웨어의 뛰어난 발전에도 우리는 효과적인 코드를 얻어내지 못하는가? 여기엔 몇 가지 이유들이 있다.
  - CPU limitation: cpu는 기본적으로 계산해주는 기계일 뿐, 코드를 더 효율적인 형태로 변형해주지는 못한다. bubble sort를 실행할 때 다른 형태로 바꾸는 게 아님.
  - Compiler limitation: 코드 변형이 가능하지만 완벽하지는 않다. 결국 컴파일러는 일종의 규칙에 의해 동작하게 되는데, "항상 효율적이라고 기대되는 변형규칙"은 많지 않기 때문. 휴리스틱을 통해 수행되는 경우가 많다. 컴파일러가 만들어줘도 더 효과적인 코드를 만드는 것도 가능하고.
  - 알고리즘 복잡도 분석 limitation: 크게 두가지 한계가 있음. 1) big-o에서 더 좋아도 실제로 다를 수 있음. n이 50이하면 삽입정렬이 퀵정렬보다 좋다고 함. 2) low-level 최적화 관측이 어려움. branch prediction / cache miss 같은 건 알고리즘 복잡도 분석으로 해결하기 어려움.
